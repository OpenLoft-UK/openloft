# OpenLoft marketing site

A responsive, conversion-focused marketing site for OpenLoft's domestic loft boarding service.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Before launch

- Connect the survey form in `src/main.ts` to the chosen CRM or form endpoint.
- Replace format-only postcode validation with real launch-area coverage data.
- Confirm package prices, service terms and all operational claims.
- Add final company contact details, privacy policy and terms.

Photography sources are recorded in `CREDITS.md`.
